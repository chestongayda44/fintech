Open a pull request for the stress panel. Write the description to PR_BODY.md for a reviewer:
what changed and why, how it's tested, and what to check (keep it short). Then run exactly
`bash scripts/open-pr.sh "<title>"` with a plain one-line title (no quotes, backticks or $).
Don't run any other git or gh commands. Reply with the pull request link.
